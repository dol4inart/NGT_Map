# Карта общественного транспорта Новосибирска (NGTMap)

Мобильное приложение на Flutter для отображения общественного транспорта Новосибирска в реальном времени.

## Возможности

- Просмотр маршрутов общественного транспорта (автобусы, троллейбусы, трамваи, маршрутные такси)
- Отображение маршрута и транспорта на карте (OpenStreetMap)
- Отображение остановок на карте
- Просмотр информации о транспортных средствах (график, скорость, расписание, наличие низкого пола/аппарели)
- Просмотр названий остановок
- Добавление маршрутов в избранное (на главном экране и на экране карты)
- Переключение между избранными и общим списком маршрутов в выпадающем списке
- Ручное обновление данных по транспорту по кнопке на экране карты

## Установка

1. Установите зависимости:

```bash
flutter pub get
```

2. Соберите и запустите приложение на устройстве/эмуляторе Android:

```bash
flutter run -d "имя_устройства"
```

> Приложение не требует API‑ключей карт: используется OpenStreetMap через `flutter_map`.

## Структура проекта

- `lib/main.dart` — точка входа в приложение
- `lib/models/` — модели данных:
  - `route.dart` — группы маршрутов и отдельные направления (`TransportRouteGroup`, `RouteWay`)
  - `vehicle_marker.dart` — маркеры транспорта
  - `route_path.dart` — путь следования маршрута и остановки
- `lib/services/` — сервисы:
  - `api_service.dart` — запросы к API гортранса (маршруты, маркеры, пути)
  - `favorites_service.dart` — работа с избранными маршрутами (`SharedPreferences`)
- `lib/screens/` — экраны:
  - `home_screen.dart` — главный экран с избранными маршрутами и выбором транспорта
  - `map_screen.dart` — экран карты с маршрутом, остановками и транспортом

## API

Приложение использует API Новосибирского городского транспорта:

- Список маршрутов: `https://map.nskgortrans.ru/listmarsh.php?r&r=false`
- Маркеры транспорта: `https://map.nskgortrans.ru/markers.php?r={type}-{marsh}-W-{name}`
- Путь маршрута: `https://map.nskgortrans.ru/trasses.php?r={type}-{marsh}-W-{name}`

Где:

- `type` — тип транспорта:
  - 0 — автобус (в запросе маркеров/маршрута используется 1)
  - 1 — троллейбус (в запросе — 2)
  - 2 — трамвай (в запросе — 3)
  - 7 — маршрутное такси (в запросе — 8)
- `marsh` — код маршрута для API
- `name` — номер маршрута (отображаемый и для API)

Основные поля маркеров транспорта:

- `lat`, `lng` — координаты транспорта (широта/долгота)
- `azimuth` — направление движения
- `title` — номер маршрута
- `graph` — номер графика
- `time_nav` — время последнего обновления
- `rasp` — расписание (парсится в человекочитаемый текст)
- `speed` — скорость
- `ramp` — наличие низкого пола/аппарели (1/0)

## Карта и визуализация

- Карта — **OpenStreetMap** через `flutter_map`:
  - `TileLayer` c `https://tile.openstreetmap.org/{z}/{x}/{y}.png`
  - стандартная система координат WGS‑84 (lat/lng)
- Маршрут:
  - строится как полилиния по точкам из `trasses.php`
- Остановки:
  - точки с полем `n` в ответе `trasses.php`
  - выводятся отдельными маркерами (белый круг с иконкой автобуса)
- Транспорт:
  - маркеры в виде стрелок (`Icons.navigation`), повёрнутых по азимуту
  - поворот стрелки рассчитывается по формуле:
    \[
    az_{corr} = ((-az_{api} + 85) \bmod 360 + 360) \bmod 360
    \]

## Зависимости

Основные пакеты:

- `flutter_map` — отображение карт (OpenStreetMap)
- `latlong2` — работа с координатами
- `http` — HTTP‑запросы к API
- `shared_preferences` — хранение избранных маршрутов
- `provider` — управление состоянием (по необходимости)
