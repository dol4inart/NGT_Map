# Инструкции по созданию иконок для карты

Для работы приложения необходимо создать две иконки:

## 1. Иконка остановки (assets/stop_marker.png)

- Размер: 24x24 пикселей
- Формат: PNG с прозрачностью
- Дизайн: Красный круг диаметром 16px на прозрачном фоне
- Цвет: #FF0000 (красный)

## 2. Иконка транспорта (assets/bus_marker.png)

- Размер: 24x24 пикселей
- Формат: PNG с прозрачностью
- Дизайн: Синий прямоугольник со скругленными углами (20x20px) на прозрачном фоне
- Цвет: #2196F3 (синий)
- Форма: Прямоугольник, похожий на автобус

## Альтернативный вариант

Если у вас нет графического редактора, вы можете использовать простые цветные круги/прямоугольники или использовать встроенные иконки Material Design через код.

Для быстрого старта можно временно использовать любые простые иконки 24x24px.
